# 💆‍♀️ AI-Powered Skin Care Product Planner  

An AI-driven skincare recommendation system built with **Streamlit**, **Gemini AI**, **CrewAI**, and **LangChain**, designed to provide **personalized product suggestions** based on **skin type** and **budget**.  

---

## 🚀 Features  
- 🧠 **AI-Powered Recommendations:** Uses Gemini AI and LangChain for intelligent, context-aware skincare suggestions.  
- 💸 **Smart Filters:** Personalized results based on **skin type** and **budget range**.  
- ⚡ **Instant Results:** Real-time recommendations with a responsive **Streamlit web app** interface.  
- 🤖 **Automation with CrewAI:** Integrated CrewAI agents for dynamic decision-making and process handling.  
- 🎨 **User-Friendly UI:** Clean, minimal interface designed for simplicity and engagement.  

---

## 🧰 Tech Stack  
- **Languages:** Python  
- **Frameworks & Tools:** Streamlit, CrewAI, LangChain, Gemini AI API  
- **Libraries:** Pandas, NumPy, Requests, JSON  
- **Version Control:** Git, GitHub
